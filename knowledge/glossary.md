# Glosarium

| Istilah | Arti |
| --- | --- |
| CONFIRMED | Fakta yang sumbernya disebut dan sudah diperiksa, atau dikonfirmasi pemilik |
| INFERRED | Kesimpulan dari bukti yang tersedia |
| UNKNOWN | Belum diketahui |
| OUTDATED | Pernah benar, kelayakannya sekarang belum diuji ulang |
| sensitivity public | Aman dibaca di repository public |
| sensitivity internal | Untuk pemilik dan tim. Tidak aman di remote public saat ini |
| sensitivity restricted | Tidak boleh di-commit |
| probation-review | Antrean log AI sebelum migrasi |
| digest | Indeks generated, bukan sumber kebenaran |
| owner | Peran yang bertanggung jawab meninjau dokumen. `unassigned` berarti belum ada orang yang ditunjuk |
