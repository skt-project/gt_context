# Onboarding tim eksternal

Tim yang hanya membutuhkan satu proyek tidak perlu membaca profil pribadi.

1. Baca [indeks proyek](../../projects/README.md).
2. Buka satu berkas di `projects/active/`, `completed/`, atau `archived/` bila sudah ada.
3. Jika proyek belum dipindahkan, baca baris yang sesuai di [katalog](../../projects/catalog/direktori-lokal.md) dan repository asal yang disebut di sana.
4. Anggap klaim README sebagai klaim dokumen sampai ada verifikasi baru.

Pada 2026-10-14 belum ada berkas di folder siklus hidup. Jangan meminta akses ke `context/` atau `systems/` bila pekerjaan tidak membutuhkannya.

Jangan menyalin cuplikan ini ke saluran public. Remote knowledge base sendiri masih public sampai visibilitasnya diubah.
