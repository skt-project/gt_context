# Ikhtisar konteks

Repository ini menyimpan konteks kerja agar manusia atau AI yang baru datang tidak memulai dari nol. Scaffold dibuat pada 2026-10-14 dari audit remote dan inventaris read-only laptop.

## Yang sudah diketahui

- Remote GitHub ada, public, dan kosong pada saat audit.
- Laptop, toolchain yang ada di PATH, dan beberapa checkout Git lokal sudah dicatat di [systems/](../systems/laptop/README.md) dan [projects/catalog/direktori-lokal.md](../projects/catalog/direktori-lokal.md).
- Dua nama identitas mesin belum disatukan. Lihat [profil](01-personal-profile.md).

## Yang belum diketahui

Peran organisasi, prioritas pribadi di luar tugas ini, tujuan jangka panjang, jaringan, browser, scheduled task, dan status siklus hidup proyek. Dokumen terkait menulis `UNKNOWN` pada bagian itu.

## Cara membaca

Mulai dari [AI_CONTEXT.md](../AI_CONTEXT.md), lalu prioritas, lalu satu proyek yang relevan. Arsitektur informasi ada di [docs/architecture/model-informasi.md](../docs/architecture/model-informasi.md).
